每篇論文的研究成果、貢獻度與未來切入方向

Paper 1｜Retrospective-Reading

成果：建立含標題、介紹、回覆、使用者與數值資訊的 Bilibili 中文反諷資料，並證明上下文與回溯閱讀能改善辨識。

貢獻度：★★★★★。資料集與上下文模型都具有明確研究價值，尤其適合延伸到個人化反諷與對話式理解。

  • 跨 Bilibili、Weibo、Douyin 的 domain adaptation。
  • 長對話階層式 Transformer 或檢索式上下文。
  • 使用者歷史資訊的匿名化與隱私保護。
  • Focal Loss、Class-Balanced Loss、重採樣與校準。

Paper 2｜CTSD Hybrid Model

成果：建立 28,630 筆 CTSD 與 16,004 筆平衡版；混合 BERT-wwm、CNN、BiLSTM，F1 79.07%。

貢獻度：★★★★☆。資料集是主要貢獻；模型屬穩健的組件整合，重現門檻相對合理。

  • 公開 CTSD 切分、程式、權重與完整超參數。
  • 比較全參數 fine-tune、LoRA、Adapter 與 prompt tuning。
  • 加入評論上下文、作者資訊及影片多模態訊號。
  • 跨主題與跨時間測試，避免只記住平台詞彙。

Paper 3｜Chinese Toxic Comment Review

成果：建立中文網路有毒評論的資料、模型與研究挑戰全景，並清楚區分 toxic、offensive、hate、harmful、sarcasm。

貢獻度：★★★★★（綜述）。非常適合用於博士論文第二章及研究缺口定位。

  • 統一中文 toxic benchmark 與標籤 ontology。
  • 跨平台、跨文化、跨時間的穩健性評估。
  • 多模態、反規避、同音字與迷因理解。
  • 可解釋、公平性、不確定性與人工覆核流程。

Paper 4｜DCID + DeepSeek-V3

成果：雙路徑認知模型結合 LLM 資料增強，達 F1 89.29%、Accuracy 89.43%、AUC 96.06%。

貢獻度：★★★★★。但應分開解讀：DCID 架構本身約 +1.73 F1 百分點，主要提升來自資料增強。

  • 建立人工盲評，檢查生成樣本是否真的保留反諷。
  • 比較 DeepSeek、Qwen、Llama 等生成器與成本。
  • 防止 train/test 語義近重複與資料洩漏。
  • 跨平台測試、知識蒸餾、量化與即時部署。

四篇論文主要技術流程

下列流程圖不只畫出資料輸入與模型輸出，也標示哪些元件屬於預訓練模型、哪些元件需要 Fine-tune，以及資料增強或評估所在位置。

Paper 1｜Bilibili Context Dataset → Retrospective-Reading Model

資料集來源與蒐集

語言：中文。來源為 Bilibili。研究先蒐集 108,641 則評論，保留標題、介紹、回覆、使用者與按讚等上下文，再經人工標註形成 76,231 非反諷與 2,814 反諷。

開源狀態與連結

部分公開資料集已提供 GitHub；完整訓練程式與已訓練權重是否公開，附件未明確證實。

GitHub：zhstattem/dataset

Dataset 流程

  1. 從 Bilibili 收集評論與完整社群上下文。
  2. 人工判定反諷／非反諷，最終得到 76,231 非反諷與 2,814 反諷。
  3. 建立不平衡真實分布與平衡實驗版本，以避免只看 accuracy。
  4. 將標題、介紹、回覆、使用者資訊與數值資訊整理成模型欄位。

模型與 Fine-tune

預訓練文字表示只負責將中文文本轉為上下文化向量；真正的創新在 Sketchy Reading 與 Intensive Reading。訓練時，文字編碼器、兩個閱讀模組及分類器共同以反諷標籤進行監督式更新。

輸出：反諷機率與二元標籤。最佳結果：F1 0.6942。

Paper 2｜CTSD → BERTWWM-CNN-BiLSTM Fine-tune

資料集來源與蒐集

語言：中文。來源為 Douyin／Chinese TikTok，涵蓋 128 個主題。人工標註後建立完整 CTSD 28,630 筆及 1:1 平衡版 16,004 筆。

模型來源與開源狀態

基礎模型開源BERT-wwm 由 HFL 提供，Apache-2.0；論文專屬訓練程式與 fine-tuned 權重未確認公開。

Hugging Face：hfl/chinese-bert-wwm-ext
GitHub：Chinese-BERT-wwm

模型角色分工

  • BERT-wwm：中文整詞遮罩預訓練，產生深層上下文表示。
  • CNN：擷取局部 unigram／bigram／trigram 類型的反諷詞組。
  • BiLSTM：從前後兩個方向學習遠距依賴與語序。
  • 融合分類頭：串接多路特徵後做二元分類。

Fine-tune 說明

BERT-wwm 是預訓練基礎模型；研究不是只抽固定 embedding，而是將 BERT-wwm 與新增的 CNN、BiLSTM、全連接層一起在 CTSD 上監督式 Fine-tune。訓練目標為最小化二元分類損失，驗證指標包括 F1 與 AUC。

Paper 3｜Systematic Review：資料集 → 分類框架 → 模型演進 → 開放問題

資料來源與語言

語言：以中文網路內容為核心。資料不是單一爬蟲建立，而是彙整 Weibo、Zhihu、Tieba、Bilibili、Douyin、PTT、Plurk 等既有資料集與研究。

模型與開源狀態

不適用單一模型本篇為 review，沒有一個需要下載或 fine-tune 的專屬分類器。文中每個被回顧模型的開源狀態不同。

arXiv 論文頁

重要：Paper 3 是文獻回顧，不是提出並 Fine-tune 一個單一模型。因此其「技術流程」是系統性蒐集、分類、批判與形成研究議程，而不是一般的資料→訓練→預測流程。

Dataset 層面輸出

建立資料集比較矩陣：來源平台、研究任務、標籤數、規模、類別平衡、是否公開。此流程用來發現資料規模不足、定義不一致、單平台偏差、時效性不足與類別不平衡。

模型層面輸出

將模型分為規則式、傳統機器學習、深度學習、預訓練模型、Prompt／LLM、多任務與多模態；特別指出可解釋性是內容治理部署不可缺少的部分。

Paper 4｜CTSD + DeepSeek-V3 → DCID 雙路徑 Fine-tune

資料來源與蒐集

語言：中文。沿用 CTSD 的 Douyin 人工標註評論，再以 DeepSeek-V3 依標籤控制 Prompt 生成同標籤改寫，擴充表層語言形式。

模型來源與開源狀態

基礎 LLM 開源／DCID 未確認DeepSeek-V3 有官方 GitHub 與 Hugging Face；DCID 專屬程式與權重未確認公開。

DeepSeek-V3 官方 GitHub
DeepSeek-V3 Hugging Face

DeepSeek-V3 的角色

DeepSeek-V3 是資料生成器，不是最終分類器，也不是本文主要被 Fine-tune 的模型。研究用標籤感知 Prompt 生成與原樣本語意一致、但表面措辭不同的新樣本，藉此緩解資料不足。

重現時必須保存 Prompt、temperature、生成數量、去重與品質過濾規則，否則結果難以一致。

DCID Fine-tune

文字編碼器、MSCD、EETT 與分層融合模組在 CTSD＋擴增資料上共同監督式訓練。MSCD 負責「語義不一致」，EETT 負責「情緒軌跡」，最後分類頭輸出反諷機率。

貢獻分解：架構本身 79.07→80.80；DeepSeek 增強後 80.80→89.29。

四篇論文的研究發展關係

最重要的研究判讀：Paper 4 的大幅提升不能全部歸因於 DCID 架構。論文的貢獻分解顯示，架構本身帶來約 1.73 個百分點 F1，而 LLM 資料增強帶來約 8–9 個百分點，因此未來重現研究必須分開比較「模型架構效果」與「生成資料效果」。
