本頁說明 ZIP 中 code/ 目錄的每個程式檔案用途、主要變數與函式。

二、核心變數說明

metadata_path

資料集標註檔路徑。例如 MUStARD 的 sarcasm_data.json 或 MCSD 的 metadata.csv。

feature_dir

特徵輸出資料夾。文字、語音、影像特徵通常會以 .npy 儲存，避免每次訓練都重新抽特徵。

modalities

模態組合，例如 ['text']、['text','audio']、['text','audio','visual']。train_svm_fusion.py 會依這個清單串接特徵。

X, y

X 是模型輸入特徵矩陣；y 是標籤，0 表示非反諷，1 表示反諷。

四、程式碼修改建議

替換模型

若要把 BERT 換成 MacBERT，可把 model_name 改為 Hugging Face 上對應模型名稱。

加入新模態

新增 feature 檔案後，在 modalities 裡加入名稱，並在 feature loading 函式中讀取。

改融合方法

目前範例使用 concatenation。若要做 cross-attention，需要新增 PyTorch 模型，不再只用 SVM。
