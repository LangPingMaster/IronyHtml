二、資料取得流程

1、先閱讀授權
確認資料集是否允許研究、教學、再散布或只允許下載 metadata。
2、下載 metadata 或 official features
MUStARD 建議先用官方 features；MCSD 先下載 metadata；SarcNet 可用 Hugging Face 載入。
3、整理成本 ZIP 的資料夾格式
依照 data/mustard、data/mcsd、data/sarcnet 放置原始資料與處理後特徵。
4、先跑小樣本
先用 10–30 筆確認路徑、label 與 feature 維度，再跑完整實驗。

三、下拉式注意事項

為什麼 ZIP 裡沒有直接附資料？

影片、圖片、社群貼文與模型權重可能受到平台條款與資料集授權限制。本 ZIP 提供可重現流程、程式碼與官方連結，但不重新散布原始資料。

如果影片、圖片或貼文下架怎麼辦？

先記錄缺失樣本數，優先使用官方提供的 pre-extracted features 或只重現 text-only baseline。報告中需要清楚註明資料缺失與實驗條件差異。
