環境與硬體配備

本頁說明重現三篇論文時建議使用的電腦配備、Python 套件與資料夾結構。

一、硬體配備建議

最低可行配備

CPU：Intel i7 / Ryzen 7 以上；RAM：32GB；GPU：RTX 3060 12GB 以上；SSD：1TB。可以跑 BERT embedding、Librosa、ResNet、SVM 與小型 ViT 訓練。

建議研究配備

CPU：Intel i9 / Ryzen 9；RAM：64GB；GPU：RTX 4090 24GB 或 A5000 / A6000；SSD：2TB。適合 TimeSformer、Wav2Vec2、VideoMAE、VLM 或 LoRA fine-tuning。

二、Python 環境

conda create -n sarcasm-mm python=3.10
conda activate sarcasm-mm
pip install torch torchvision torchaudio
pip install transformers datasets accelerate
pip install scikit-learn pandas numpy scipy
pip install librosa soundfile opencv-python moviepy pillow
pip install matplotlib tqdm ffmpeg-python

三、FFmpeg 安裝

sudo apt update
sudo apt install ffmpeg
