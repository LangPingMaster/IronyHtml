二、環境安裝指令

conda create -n sarcasm310 python=3.10
conda activate sarcasm310
pip install torch torchvision torchaudio
pip install transformers datasets tokenizers sentencepiece
pip install pandas numpy scikit-learn tqdm matplotlib
pip install pillow opencv-python timm
pip install librosa soundfile torchaudio opensmile
pip install moviepy decord ffmpeg-python
pip install pytorch-lightning accelerate evaluate peft
pip install opencc jieba ckip-transformers

三、套件用途

套件用途
transformers載入 Chinese-BERT、MacBERT、RoBERTa、CLIP。
timm / torchvisionViT、Swin、ResNet 圖像特徵擷取。
librosa / torchaudio音訊切割、頻譜、Wav2Vec2 特徵。
moviepy / decord影片切段、抽幀、轉音訊。
pytorch-lightning統一訓練流程、checkpoint、log。
