博士論文研究執行架構

一步一步完成整體研究架構

從環境建立、資料建置、標註平台、特徵擷取、模型訓練到論文整合的完整執行方法。

一、一步一步完成整體架構

二、第一階段：環境建立

  1. 安裝 Ubuntu 22.04 或 WSL2。
  2. 安裝 NVIDIA Driver、CUDA、cuDNN。
  3. 建立 conda 環境。
  4. 安裝 PyTorch 與 transformers。
  5. 建立 GitHub repository。

三、第二階段：資料建置

  1. 決定資料來源：Dcard、PTT、Threads、微博、影音平台。
  2. 蒐集文字、圖片、影片、上下文。
  3. 建立 metadata 與資料 ID。
  4. 清理雜訊、去重、繁簡轉換。
  5. 建立 corpus.csv。

四、第三階段：標註平台

  1. 建立 Web annotation app。
  2. 顯示文字、圖片、影片與上下文。
  3. 標註 text/image/audio/video/multimodal。
  4. 三位標註者交叉標註。
  5. 計算 Cohen’s Kappa 或 Fleiss’ Kappa。

五、第四階段：模型訓練

  1. 訓練 Text-only baseline。
  2. 訓練 Image-only、Audio-only、Video-only。
  3. 建立 Early Fusion 與 Late Fusion。
  4. 訓練 Cross-Attention Fusion。
  5. 加入 Metaphor-Irony Reasoning Layer。

六、48 個月執行時程

月份工作成果
0–6文獻整理、環境建立、資料來源確認研究計畫書、資料規格
6–12資料蒐集、清理、標註平台初版華語多模態語料庫
12–18標註一致性、Baseline 重現Corpus / Benchmark paper
18–30多模態融合、隱喻－反諷模型核心模型論文
30–42消融實驗、可解釋分析、錯誤分析Explainable AI / Ablation paper
42–48博士論文整合與投稿博士論文與期刊投稿
