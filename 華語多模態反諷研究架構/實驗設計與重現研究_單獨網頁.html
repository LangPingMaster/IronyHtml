實驗設計與重現研究

本頁聚焦於 MUStARD、MCSD、SarcNet 三個代表性研究的重現策略，並延伸到華語多模態反諷辨識模型的 fine-tuning、融合實驗、消融分析與最終目標。

一、主題定位：為什麼要做「實驗設計與重現研究」？

本研究的博士論文主軸是「華語多模態反諷辨識之 AI 模型研究」，因此實驗設計不能直接跳到自建模型，而應先完成代表性研究的重現。重現研究的目的有三個：第一，確認研究者已具備處理多模態資料的實作能力，包括文字轉錄、音訊切段、影像取幀、特徵擷取、模型訓練與評估；第二，建立可比較的 baseline，避免後續模型改良缺乏基準；第三，找出華語反諷辨識相對於英文資料、圖文資料與影音資料的差異。

本頁將實驗設計分成四層：第一層是重現 MUStARD、MCSD 與 SarcNet；第二層是建立單模態 baseline，包括文字、語音、視覺與語境；第三層是建立多模態融合模型，包括 concatenation、late fusion、gated fusion、cross-modal attention 與 multimodal transformer；第四層是 fine-tune 到最終目標，也就是建立能處理華語文字、語音、影像、語境與隱喻反諷交互的模型。

下圖呈現本主題的完整技術路線。左側從三個代表性資料集與文獻開始，先完成資料整理與 baseline 重現；中段進入華語資料轉換與特徵擷取；右側則進入多模態融合、fine-tuning、消融實驗與最終華語多模態反諷理解系統。

三、三個代表性重現研究

（一）MUStARD 重現：英文影音反諷 baseline

MUStARD 是多模態反諷辨識的經典資料集，資料來自電視劇或節目片段，每筆 utterance 具有文字轉錄、語音、影像與對話語境。重現 MUStARD 的目的，是建立影音多模態資料處理與 baseline 訓練能力。建議先重現 text-only，再加入 audio-only、visual-only 與 text+audio+visual。

  • 資料來源：MUStARD GitHub：https://github.com/soujanyaporia/MUStARD
  • 論文來源：ACL Anthology：Towards Multimodal Sarcasm Detection
  • 文字模型：BERT-base / sentence embedding。
  • 語音特徵：Librosa MFCC、Mel-spectrogram、spectral centroid。
  • 視覺特徵：ResNet 或 ViT frame-level embedding。
  • 分類器：SVM、Logistic Regression、MLP。

（二）MCSD 重現：中文多模態反諷資料集

MCSD 是本研究最重要的華語參考資料，重點在中文影片、語音線索與標註信心。重現 MCSD 可直接建立華語反諷辨識 baseline。建議依照原研究採用 Chinese BERT、Wav2Vec2 與 TimeSformer 進行特徵擷取，再以 SVM 或 MLP 分類。

  • 論文來源：ISCA Archive：A Multimodal Chinese Dataset for Cross-lingual Sarcasm Detection
  • 標註設計來源：MCSD GitHub Wiki：https://github.com/x-y-g/MCSD/wiki
  • 文字模型：bert-base-chinese。
  • 語音模型：Wav2Vec2 Chinese 或 HuBERT。
  • 影片模型：TimeSformer 或 VideoMAE。
  • 重現重點：比較 T、A、V、T+A、T+V、A+V、T+A+V。

（三）SarcNet 重現：圖文反諷與分模態標註

SarcNet 的重點不是影音，而是圖文反諷與分模態標註。它將 text label、image label 與 multimodal label 分開，對本研究的標註設計非常重要。重現 SarcNet 可讓研究者理解「文字單獨不反諷、圖片單獨不反諷，但圖文組合形成反諷」的資料結構。

  • 論文來源：ACL Anthology：SarcNet: A Multilingual Multimodal Sarcasm Detection Dataset
  • 資料來源：SarcNet GitHub：https://github.com/yuetanbupt/SarcNet
  • 文字模型：BERT、Multilingual BERT、XLM-RoBERTa。
  • 圖像模型：ResNet、MobileNetV3、ViT、CLIP。
  • 多模態模型：DT4MID 或自建 cross-modal attention。
  • 延伸重點：將分模態標註觀念轉移到華語影音資料。

六、如何 fine-tune 到最終目標模型？

Step 1：先抽取 embedding，不急著 fine-tune

第一階段不要直接訓練大型多模態模型，而是先將文字、語音、視覺與語境各自抽取成固定 embedding。例如文字使用 BERT 的 [CLS] embedding，語音使用 Wav2Vec2 的 pooled embedding，視覺使用 ViT 或 TimeSformer 的 pooled embedding。接著使用 SVM 或 MLP 訓練 baseline。這一步能快速驗證資料是否可用，也能建立後續比較基準。

Step 2：單模態 fine-tune

第二階段分別 fine-tune 文字、語音與視覺模型。文字模型可使用 target utterance，或將 context 與 target 串接為「[context] [SEP] [target]」。語音模型輸入切好的 utterance audio，視覺模型輸入 frames 或 video clips。此階段目標是建立最強單模態模型，避免後續多模態模型只是因為文字 baseline 太弱而看似有效。

Step 3：雙模態與三模態融合

第三階段建立 T+A、T+V、A+V 與 T+A+V 模型。最簡單的方法是將 embedding concat 後送入 MLP；進階方法可加入 gated fusion，讓模型自動決定哪個模態更重要；再進一步可使用 cross-modal attention，讓文字特徵查詢語音與影像線索，捕捉「文字表面正向、語氣或畫面負向」的不一致。

Step 4：加入語境與隱喻反諷特徵

第四階段加入 context encoder 與 metaphor-irony features。語境可以是前一至三句，也可以是整段對話。隱喻特徵可先使用人工標註欄位，例如 metaphor_label、metaphor_irony_interaction，再作為額外特徵加入分類器。最終目標不是只判斷反諷，而是讓模型能說明反諷來自文字、語音、影像、語境或隱喻評價反轉。

Step 5：最終模型輸出格式

{
  "prediction": "sarcasm",
  "confidence": 0.91,
  "text_score": 0.72,
  "audio_score": 0.84,
  "visual_score": 0.63,
  "context_score": 0.88,
  "metaphor_irony_interaction": true,
  "main_trigger": "audio + context",
  "explanation": "文字表面為稱讚，但語氣拖長且前文為負面事件，因此判定為反諷。"
}
博士論文寫法建議：每一次 fine-tune 都必須保存資料切分、random seed、learning rate、batch size、epoch、checkpoint、macro F1、weighted F1、confusion matrix 與錯誤案例。這樣後續論文才能清楚說明模型提升來自哪一個組件。

七、實驗矩陣設計

實驗矩陣應由簡入繁，從單模態到多模態，再加入語境與隱喻。這樣才能回答「多模態到底有沒有幫助」、「哪個模態最重要」、「語境是否提升模型」、「隱喻反諷是否造成模型困難」。

實驗代號輸入模態模型目的主要指標
E1TBERT / MacBERT建立文字 baselineMacro F1
E2AWav2Vec2 / HuBERT檢驗華語語音反諷線索Macro F1
E3VViT / TimeSformer檢驗表情與視覺線索Macro F1
E4T+AConcat / Gated Fusion檢驗文字與語音互補Macro F1、錯誤分析
E5T+VCLIP / Cross Attention檢驗圖文或影音視覺不一致Macro F1
E6T+A+VMultimodal Transformer建立三模態主模型Macro F1、Ablation
E7T+A+V+CContext-aware Fusion檢驗語境貢獻Macro F1、FN 改善
E8T+A+V+C+MMetaphor-Irony Model檢驗隱喻反諷交互案例分析、可解釋性

消融實驗

  • Full Model：T + A + V + Context + Metaphor features。
  • – Text：移除文字，檢查模型是否過度依賴文字。
  • – Audio：移除語音，檢查華語反諷語氣的貢獻。
  • – Visual：移除影像，檢查表情與畫面反差是否有效。
  • – Context：移除語境，檢查是否造成字面正向案例誤判。
  • – Metaphor：移除隱喻交互特徵，檢查含隱喻反諷案例是否下降。

訓練流程 pseudo-code

# 1. 載入資料
manifest = load_manifest("data/processed/train.csv")

# 2. 抽取各模態特徵
text_emb = TextEncoder("hfl/chinese-macbert-base")(manifest.text)
audio_emb = AudioEncoder("wav2vec2-chinese")(manifest.audio_path)
visual_emb = VideoEncoder("timesformer")(manifest.video_path)
context_emb = ContextEncoder("bert-base-chinese")(manifest.context)

# 3. 多模態融合
fusion = CrossModalFusion()
z = fusion(text_emb, audio_emb, visual_emb, context_emb)

# 4. 分類
logits = classifier(z)
loss = cross_entropy(logits, labels)

# 5. 評估
metrics = compute_metrics(logits, labels)
save_results(metrics, confusion_matrix, error_cases)
